# 機械可読な契約を持たない出荷面 assert を削除する

## Context

出荷済み scaffold の回帰検査には、機械可読な契約を持つ対象と、契約を持たない叙述が混在している。

前者には、Makefile のタスク名集合とタスク依存、設定ファイルのキーと値、export 境界の分類、ファイルの実在、export 済みツリーでコマンドを起動して観測できる挙動がある。
これらは構造として解釈でき、値や挙動の変化を意味のある不一致として検出できる。

後者には、README や運用文書、command adapter が特定の案内文を含むかを部分文字列で調べる検査がある。
これらの叙述には検査が束縛できる機械可読な契約がない。
緩い部分一致は、語が無関係な箇所に現れる場合や否定された命令でも合格しうる。
一方、一致条件を完全な文や隣接関係へ強めると、意味を保った言い換えでも失敗する。
一致を緩めても強めても、意味を安定して検査できない。

検査の配置を変更しても、契約を持たない叙述を直接照合する限り、この脆さは残る。
また、この問題のために新たな強制機構を設けることは求められていない。

## Decision

### D1: 機械可読な契約を持たない対象への assert を削除する

出荷面の回帰検査から、検査対象が機械可読な契約を持たない assert を削除する。

対象の境界は次のとおりとする。

- **削除する**: README、運用文書、command adapter の叙述に対する一致検査。特定の語句、命令文、言い回しが本文に含まれるかを調べるもの。機械可読な形式を持つファイルであっても、形式を解釈せず本文へ生の部分文字列一致を行うものは削除する。
- **維持する**: パース可能な構造を解釈して要素や値を照合する検査、および export 済みツリーで実行して観測する挙動検査。Makefile のタスク名集合とタスク依存、設定ファイルのキーと値、export 境界の分類、ファイルの実在を含む。

判定は、assert が検査する対象に機械可読な契約があり、その契約に束縛されているかで行い、検査事項の重要度では行わない。
対象ファイルに形式があっても、パースせず本文へ生の部分文字列一致を行う assert は構造検査に当たらない。
削除した検査が扱っていた事項は人手のレビューで確認する。
その検査を残すための新たな契約や再発検出機構は導入せず、検査の配置も変更しない。

本決定は、`2026-07-23-0117-export-surface-minimization.md` D4 と `2026-07-23-0115-scaffold-first-run-experience.md` D1 を、機械可読な契約に対する構造的なスモーク検査の範囲に精緻化する。
両決定が要求する出荷 Makefile の検査は維持するため、いずれも supersede しない。

## Rejected Alternatives

### A. 部分一致を完全な命令文や隣接関係の一致へ強める

否定形や無関係な箇所への一致による偽陽性は減るが、意味を保った言い換えで失敗する。
機械可読な契約がないことを解消せず、固定する文言の粒度を変えるだけなので採らない。

### B. 検査を別の配置へ移す

Rust の統合テストより外側の検証面へ移せば層方向の問題は解消できる。
しかし、叙述への直接照合である限り脆さは変わらない。
本決定では検査配置を見直さない。

### C. 出荷面の回帰検査をすべて削除する

機械可読な契約を持つ構造や実行時挙動の有効な検査まで失われる。
既存決定が要求する出荷 Makefile の乖離検出を維持できないため採らない。

### D. 叙述に機械可読な契約を新設する

叙述のための新たな SSoT と同期責務が増える。
この問題に関して新たな機構を設けないという境界を越えるため採らない。

## Consequences

### Positive

- README と運用文書を、意味を保った言い換えで検査失敗させずに保守できる。
- 残る検査は、機械可読な契約または観測可能な挙動との不一致を示す。
- 否定形や無関係な箇所への部分一致による偽陽性を除去できる。

### Negative

- 削除した検査が扱っていた案内の妥当性は、機械検査ではなく人手のレビューに委ねられる。
- 削除対象の判定を誤ると、機械可読な契約に対する有効な検査を失いうる。

### Neutral

- 検査の配置は変更しない。
- 出荷 Makefile、設定、export 境界など、機械可読な契約を持つ対象の検査は維持される。
- 再発検出のための新たな強制機構は追加しない。

## Reassess When

- 出荷文書の案内誤りが人手のレビューを通過し、利用者へ到達したとき。
- 運用文書に、叙述と独立して検査できる機械可読な契約が導入されたとき。
- 残した検査配置が、叙述 assert の脆さとは別の実害を生んだとき。
